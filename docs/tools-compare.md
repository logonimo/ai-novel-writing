# 主流 AI 写作工具对比（我实际用过的体验）

> 本文是我个人视角的对比，非恰饭。结论随版本变化，以实际体验为准。

## 快速对比表

| 工具 | 优点 | 不足 | 适合场景 |
|---|---|---|---|
| DeepSeek | 便宜、中文不错、上下文长 | 长文偶有设定漂移 | 本地自用 / 长篇主打 |
| Claude (Sonnet/Opus) | 文笔和"人味"最好，长文自洽强 | 贵、需科学上网/中转 | 精品章节 / 润色 |
| ChatGPT (GPT-4o) | 综合稳、工具生态全 | 小说感偏"通用"、稍贵 | 通用写作 / 头脑风暴 |
| 百度文心 / 通义 | 国内直连、合规 | 小说文笔较平、AI 味重 | 快速草稿 |
| 腾讯混元 | 国内生态、便宜 | 长文保持力一般 | 短篇 / 大纲 |

## 我的主用组合

- **大纲 + 设定**：DeepSeek（便宜耐造，来回改不心疼）
- **正文初稿 + 去 AI 味**：Claude Sonnet（文笔最像人）
- **灵感不会编**：ChatGPT 头脑风暴
- **国内发布前合规检查**：文心/通义 兜底

## 关键提醒

1. **没有"最好"只有"合适"**——上面是体验，不是定论，自己试 3 天见真章。
2. **省钱策略**：设定/大纲这类"来回聊"的任务走便宜模型；真正要质量的成品交给贵的。
3. **资料合规**：国内写作上架，务必确认用国内模型或本地部署，避免内容审核/合规风险。
