# 去 AI 味改稿清单：让 AI 稿不再是「一眼假」

> **一句话结论**：改 AI 稿的关键不是换模型，而是打碎它"什么都给得均匀"的那份平——按下面 5 个动作逐条扫一遍，假味能掉一大半。

很多人把"AI 味"当成模型问题，换个工具就好了。真正改过几十万字 AI 初稿就会发现：问题基本不在模型，在改稿这一步。下面每个动作都能在原文里指出具体位置，不需要灵感，是机械操作。

## 动作一：三连排比，砍到只剩一句

```
AI 原稿：写作是一场与自己的对话，是一次对内心的探索，更是一段通往自由的旅程。
改后：  写作真正烦人的，是写到一半发现前面某个设定自己都忘了。
```

三个短句并排，读着顺口，其实什么都没说。把中间那句删掉；能互换位置的词都别留——能互换，说明它本来就不承载信息。

## 动作二：情绪不要直接报，换成动作

```
AI 原稿：他心中一紧，一股不安的情绪涌上心头，不禁攥紧了拳头。
改后：  他把杯子往桌上一放，水晃出来一半，没去擦。
```

"心中一紧""涌上心头"是情绪的名字，不是情绪本身。把情绪名词删掉，只留动作和身体细节；细节要挑"只有他此刻会做"的那一个，谁都能做的动作等于没写。

## 动作三：破折号当连接词，一章留一两个就够

```
AI 原稿：他想说点什么——却什么也没说——最后只是——叹了口气。
改后：  他想说点什么，最后只是叹了口气。
```

多数地方根本不需要停顿，是句子本身没写好，才靠标点撑节奏。同类的还有"不是……而是……""不仅……而且……"，扫一遍，能删就删。

## 动作四：对话删掉提示语，让人物不正面回答

```
AI 原稿：「你为什么要这么做？」她问道。「因为我想保护你，」他认真地回答。
改后：  「你到底想干嘛。」　「……你家楼下那家面馆还开着吗。」
```

删掉"她问道""他认真地回答"这类提示语，阅读不受影响反而更干净；再让其中一个人不正面回答，读者的信息量反而更大——他会自己去猜那句没说出口的话。

## 动作五：结尾不许升华

```
AI 原稿：这一刻，他终于明白了成长的意义。
改后：  删掉这句，收在前一句场景描述里就停。
```

升华是"告诉"读者，不是"让"读者感受到。停在最后一个动作或最后一句话上，更有回味。

## 加餐：每场戏塞一个"没用"的细节

```
雨越下越大。他把外卖盒压在窗台上，怕风掀翻。
```

这个细节删掉，剧情毫发无损——那它就对了。AI 写东西每一句都"有用"，均匀得像说明书，缺的正是这种没用但真实的东西。

## 可量化的检测信号（扫稿时对照）

| # | 信号 | 触发阈值 |
|---|---|---|
| 1 | 长破折号 `——` | 每 300 字 > 1 处 |
| 2 | 三连排比 | 单段出现 ≥ 1 组 |
| 3 | "一……就……"句式 | 全篇 ≥ 3 处 |
| 4 | 情绪名词直述（紧张/悲伤/深刻地） | 每章 > 3 处 |
| 5 | 对话提示语（"他说道"） | 每章 > 5 处 |
| 6 | 结尾升华句 | 每章 ≥ 1 处即警戒 |
| 7 | 句长方差过小（全篇句子长度接近） | 通篇均匀即警戒 |

## 三步改稿流程（几分钟过一遍）

1. **搜标点**：破折号、省略号、"不是…而是…"，通篇查一遍。
2. **标情绪词**：逐个问一句——能不能换成具体动作或物体？换不了就删。
3. **制造不平**：每章挑三处长句，砍掉前后文让它孤立出来；再给每场戏塞一个"没用"的细节。
