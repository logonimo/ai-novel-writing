# AI 写网文/玄幻，怎么保证人物战力不崩？

> 一句话结论：把"力量体系地图"变成一份可查的对照表，每一章开写前让 AI 先对照它，90% 的战力崩坏能被铲掉。

## 为什么 AI 写玄幻战力必崩

AI 有大段上下文记忆，但**它对"数值"和"相对强弱"的把握是弱项**。你让它写"林远练气七层吊打赵凡"，它可能顺手让主角下一场直接秒了金丹——因为它凭"剧情需要"而不是"设定逻辑"在走。

## 解决：建一张"力量体系地图"

不要只把规则丢给 AI，而是做成**可对照的表格**，附在每次正文生成的提示词里。

```
【力量体系地图 v1.2】
- 练气期：1-9层，同层看功法/灵根
- 筑基期：初期/中期/后期/大圆满
- 金丹期：大境界，碾压筑基
- 越阶规则：主角主角=允许越 1 小阶，禁止越大境界
- 反例红线：练气七层 不得 单独斩杀 金丹修士（除非设计伏笔）
```

## 每次续写都要带的"自洽护栏"

在 `draft-prose` 或 `outline-chapter` 提示词的**末尾**追加这一段：

```
写作硬约束：
1. 所有打斗/战绩 必须对照力体系地图，禁止越界碾压
2. 本章涉及的境界、角色,先列出来再动笔
3. 如果剧情需要打破规则,在本章结尾用一句话留伏笔,不得直接硬写
```

## 效果

- 初稿阶段就带护栏 → 后期返工大减
- 埋"打破规则"的伏笔 → 反而成为爽点钩子，不显突兀
