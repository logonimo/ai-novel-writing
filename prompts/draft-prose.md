# 提示词模板 · 正文初稿生成 + 去 AI 味

> 用途：有了单章大纲后，展开正文初稿；初稿出来后用"去 AI 味"模板清理，避免读者一眼出戏。

## 模板 A：正文初稿

```
请你基于我提供的单章大纲，生成这一章的正文初稿。

【大纲】：【贴上一章生成的分镜】
【叙事视角】：第三人称，跟随主角林远的心理
【篇幅】：2000 字左右
【语言要求】：
- 用平实、有画面感的日常中文，不要华丽辞藻堆砌
- 禁止"一……就……"句式；全章破折号(——)不超过 2 处
- 人物对话要像人说话，不要像官方通告
- 不要出现"他眼神一凝""身形一闪"这类流水账废句
- 结尾停在章末钩子上，不要急着收尾升华

请直接输出正文，不要任何开场白和说明。
```

## 模板 B：去 AI 味（初稿净化）

```
请审阅我接下来给的小说段落，只做"去 AI 味"处理，不要改剧情。

重点清理：
1.  满屏破折号(——)、以及"一……就……"结构
2.  模板化的动作描写（眼神一凝 / 身形一闪 / 嘴角勾起一抹...）
3.  三段式排比、空洞升华、背景介绍式开头
4.  所有人物说话都一个口吻的问题

输出要求：
- 分两段给：第一段"修改后全文"，第二段"改了哪些&为什么"(简版)
- 保持剧情、角色、字数基本不变

【待清洗段落】：【贴初稿】
```

## 使用顺序

`大纲 → 初稿(模板A) → 去AI味(模板B) → 你手工补细节/情绪`

## 关键提示

- **初稿阶段就带上"去 AI 味"约束**（模板 A 里那些禁止项），能少走一次清洗弯路。
- 去 AI 味是"改"不是"重写"——重点清流水账和话分八股，剧情别动。
- 最终**情绪和爽点的"最后一脚"永远是你自己踩**，AI 补不了这个。
