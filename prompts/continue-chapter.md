# 续写 / 接上一章模板（AI 写长篇必备）

> 用途：写完第 N 章后，让 AI 接着写第 N+1 章而无缝衔接。AI 写长篇最大的痛点是"忘了上一章"，这个模板用"压缩记忆"解决。

## 模板

```
你继续帮我写小说下一章。为了让上下文不丢，我已把上一章和设定压成摘要贴在下面。

【世界观/力量体系摘要】：【贴 combat-power-guard 里的地图，或一句关键规则】
【已发生的关键剧情（前一章结尾的提示）】：
- 主角身处：宗门秘境第三层
- 手中底牌：刚拿到一枚上古剑胚，还没认主
- 上一章情感基调：压抑→稍见转机
- 已知伏笔：秘境核心区气息异常，长老对此三缄其口

【本章创作要求】：
1. 承接上一章结尾的张力，开场 200 字内必须接到关键情绪
2. 用对话推进剧情，至少出现一次"角色立场对立"的碰撞
3. 保持音调和 世界观/力量体系 完全一致
4. 结尾留 1 个钩子，要为下一章蓄力

请直接写 2000 字正文，不要任何说明。
```

## 关键技巧：把"上下文"压缩成摘要，而不是粘全章

- 直接粘上一章全文会让 AI 开头跑偏，且耗费上下文额度
- 只给它"位置 + 底牌 + 情感基调 + 伏笔"，它反而接得更准
- 每次续写都在摘要里带一句"势力体系规则"，杜绝战力崩

## 进阶：建立"全书记忆档案"

```
【全书档案】在每章生成后，追加一行"这章更新了什么设定/关系/坑"
- 第5章：林远获得剑胚，未认主
- 第5章：发现秘境核心异常
...
```
每章开头把这份档案 + 上一章摘要一起给 AI，长篇越写越稳、伏笔不丢。
