# 提示词模板 · 世界观 / 力量体系设定

> 用途：动笔写正文前，先用这个提示词把"世界的规矩"定死，避免前后设定打架。
> 使用方法：把 `【...】` 替换成你的内容，一句话说清楚就行，剩下的让 AI 补齐。

## 模板 A：新建世界观

```
你是一位资深网文设定架构师。请根据我提供的基础信息，帮我搭建一套完整、自洽、
可扩展的世界观设定，供后续写小说使用。

【小说类型】：玄幻
【核心创意】：主角天生灵根破碎，却意外获得吞噬他人灵力天赋的功法
【力量体系偏好】：境界层次分明，从低到高有明显成长感（类似 淬体→凝气→筑基→金丹→元婴...）
【基调】：热血、爽快，但非无脑升级流

请输出：
1. 力量体系——各境界名称、突破条件、突破时的标志性变化、同境界强弱差异来源
2. 世界的基本格局——势力分布、资源规则、人与人冲突的主驱动
3. 设定自洽清单——列出由此必然延伸出的 5 条"隐藏规则"（约束 A 就能推导出 B）
4. 潜在爽点提示——这套设定天然的升级爽、打脸爽、逆袭爽可以在哪些节点爆

要求：不要堆砌术语装高大上，规则要能自圆其说，为后续剧情服务。
```

## 模板 B：补全/校验已有设定

```
我写小说卡在设定上。这是我的现有设定草稿：
【贴你的设定】

请帮我：
1. 找出其中所有自相矛盾的地方（并列对照原文指出）
2. 标注"兄弟坑"——哪些设定埋下必然要圆的情节，防止我到后面忘了
3. 补 3 个能与现有设定自然咬合的新设定，且不能推翻原有内容
```

## 使用提示

- **别让 AI 自由发挥太多**——你给的方向越具体（力量体系偏好、基调），出来的设定越能用。
- 同一份世界观，让 AI 输出后**你亲手过一遍设定自洽清单**，比直接信它更稳。
- 这套设定文档，之后每让 AI 续写正文时，**建议把力量体系部分一起贴上**，避免它写嗨了走样。
